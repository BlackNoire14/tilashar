# Аиша Тілашар & Айым туған күн — Приглашение

Красивая интерактивная страница приглашения на свадьбу и день рождения с обратной связью (RSVP).

## Функции

- 🌸 Элегантный дизайн с казахскими орнаментами
- 🎵 Фоновая музыка с управлением воспроизведением
- ⏱️ Обратный отсчёт до события
- 📱 Адаптивный дизайн для мобильных устройств
- 💬 Форма подтверждения участия (RSVP)
- 🗺️ Интеграция с картами для навигации

## Развёртывание в Vercel

### Способ 1: Через Git (рекомендуется)

1. Инициализируйте Git репозиторий:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   ```

2. Создайте репозиторий на GitHub

3. Загрузите код:
   ```bash
   git remote add origin https://github.com/username/repo.git
   git push -u origin main
   ```

4. Подключитесь к Vercel:
   - Перейдите на https://vercel.com
   - Нажмите "New Project"
   - Выберите ваш GitHub репозиторий
   - Нажмите "Deploy"

### Способ 2: Прямое развёртывание

1. Перейдите на https://vercel.com
2. Перетащите папку проекта в интерфейс Vercel
3. Нажмите "Deploy"

## Конфигурация

Файл `vercel.json` настроен для:
- Статического хостинга (без необходимости в Node.js сервере)
- Правильной маршрутизации для SPA (все URL перенаправляются на index.html)

## Переменные окружения

В настоящий момент не требуются. Если вам нужно добавить переменные окружения в будущем, отредактируйте `vercel.json`.

## Поддержка

При возникновении проблем с развёртыванием:
1. Проверьте, что все файлы загружены (index.html, MP3-файл)
2. Убедитесь, что vercel.json имеет корректный синтаксис JSON
3. Проверьте логи Vercel в панели управления
